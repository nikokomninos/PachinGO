This major release marks the first introduction of PachinGO! to the public following our open beta!

#### Fixes
- The level editor now properly saves all custom user-defined values, which was previously affecting the wall colors if set
- The win condition now always properly triggers, which was previously affected by invisible pegs being selected to be orange
- The game can now be resized, accounting for any screen size and resolution
